# Miraj Karim - Portfolio

React (Vite) + Tailwind CSS + React Router.

## Run locally
npm install
npm run dev

## Edit content
All text (skills, education, projects, links) is in `src/data.js`.
Project screenshots go in `public/images/` (studiospace.png is missing - add it and the card will show it automatically).

## Deploy
Push to GitHub, then import the repo in Vercel (Framework: Vite). `vercel.json` already handles page refresh on project detail pages.
